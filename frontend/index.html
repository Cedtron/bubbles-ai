Desktop App Installation (Windows & Linux) Cross-Platform Ready

Run Bubbles AI as a dedicated standalone desktop application with its own window, taskbar icon, and high performance.

⚡
1-Click Browser App (PWA)
Windows 10/11, Ubuntu, Fedora, Debian

Installs directly into your operating system via Chrome, Edge, or Brave. Creates a native desktop shortcut and start menu entry.

  1. Click the button above or the install icon in your browser address bar.
  2. Confirm "Install Bubbles AI".
  3. App launches in a standalone native desktop frame!
🪟
Windows Native Package
Windows 10 / 11 (Batch Launcher)

Launches Bubbles AI in standalone window mode with its own isolated profile without URL bars or browser tabs.

Download Windows Launcher (.bat)
  1. Download launch-bubbles-ai.bat.
  2. Move it to your Desktop or pin it to your Taskbar.
  3. Double click to launch Bubbles AI instantly in desktop mode!
🐧
Linux Desktop Package
GNOME, KDE, XFCE, Ubuntu, Arch

Installs a system .desktop entry and 512x512 mascot icon into ~/.local/share/applications.

Download .sh Download .desktop
  1. Run: chmod +x install-linux.sh && ./install-linux.sh
  2. Bubbles AI will appear in your application menu with the planetary icon!
